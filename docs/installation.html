1 Installation

featureMSEA is available as a standalone R package and is also integrated into the TidyMass Shiny web application. Choose the option that best fits your workflow.

1.1 Option A — TidyMass Shiny (recommended)

The easiest way to run featureMSEA is through the TidyMass Shiny interface, which provides a point-and-click workflow without any R coding.

Access the online version:

Visit https://tidymassshiny.jaspershenlab.com — no installation needed.

Run locally:

# Install TidyMass and dependencies
remotes::install_gitlab("tidymass/tidymass")

# Install TidyMass Shiny
remotes::install_github("tidymass/tidymass_shiny")

# Launch
library(tidymass)
library(tidymassshiny)
run_tidymass_shiny()

Navigate to the fMSEA Analysis module under the Tidymass Shiny Toolkits dropdown.

1.2 Option B — R package

Install the featureMSEA R package directly for scripted workflows:

# Install from GitHub
remotes::install_github("tidymass/featureMSEA")

library(featureMSEA)

1.3 System requirements

Requirement Minimum
R version ≥ 4.1
RAM 8 GB
OS macOS, Windows, Linux

Note for macOS users: Cairo is required for graphics rendering. Install XQuartz first, then run install.packages("Cairo", type = "source").

1.4 Demo data

Demo data for following the tutorial is available on Google Drive.

The demo package contains:

  • feature_table.rda — processed feature table
  • ms1_database.rda — KEGG MS1 annotation database
  • pathway_database.rda — KEGG pathway database
